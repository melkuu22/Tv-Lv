# Что входит в эту версию

Первая рабочая петля:

регистрация → онбординг → Eco Score → главная → мой след → рекомендация → действие → прогресс.

Рядом с ней: челленджи, привычки, очки, достижения, экспорт и удаление аккаунта.

Помощник отвечает по уже посчитанным фактам. Это не внешняя языковая модель.

Сканер штрихкодов, карта точек, семейный аккаунт, OAuth, сброс пароля письмом и партнёрские предложения остаются следующими этапами. Их нет в интерфейсе, чтобы не обещать пустые экраны.
