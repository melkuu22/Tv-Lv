# Архитектура MVP

Веб-клиент (`apps/web`) и API (`apps/api`) живут в одном процессе. Клиент — статическая страница, API — TypeScript на Node.js без отдельного шага сборки.

Расчёт вынесен в `packages/calculations` и не зависит от базы. Версия формул — `eco-1.0.0`. Сохранённый score хранит эту версию и полный breakdown, поэтому старые оценки не переписываются, когда формула изменится.

Помощник получает уже посчитанные факты и только формулирует ответ. Новые килограммы и евро он не вычисляет.

Запущенный MVP пишет в SQLite (`node:sqlite`), чтобы проект открывался без отдельной СУБД. Та же модель описана для PostgreSQL в `database/migrations/001_init.sql`, справочники — в `database/seeds/001_seed.sql`.

Деньги и CO₂ сравниваются с типичными привычками в таком же жилье и при том же числе людей, а не с абстрактной квартирой.
